# java-lotto-precourse

## 프로젝트 개요
사용자가 입력한 구입 금액만큼 로또를 발행하고, 이를 당첨 번호, 보너스 번호와 비교하여 당첨 통계 및 수익률을 출력하는 프로그램입니다.

### 주요 기능
- 로또 구매 기능
- 로또 발행 기능
- 로또 당첨 확인 기능
- 로또 수익률 확인 기능

### 로또의 구성 요소
로또는 1과 45사이의 랜덤 숫자 6개로 구성이 되어있습니다.   
따라서 당첨 숫자도 똑같이 1과 45사이의 숫자 6개로 구성을 해야합니다.   
보너스 숫자는 1과 45사이의 숫자 하나로 구성됩니다.   

이는 현재 로또의 구성을 이야기하며, 로또의 룰을 바꾸고 싶으신 분은 ```LottoRule```클래스의 ```SIZE```, ```MIN_NUMBER```, ```MAX_NUMBER```의 값 수정을 통해 룰을 바꾸실 수 있습니다.

### 로또 당첨 기준
로또의 당첨기준과 내용은 다음과 같습니다.
- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원
   
이는 현재 당첨 기준을 이야기하며 ```WinningCondition``` 클래스의 상수 수정으로 당첨 기준을 수정하고 추가할 수 있습니다.
   
### 로또의 가격 설정
로또의 가격 설정은 기본으로 1000원으로 되어있습니다.

이는 현재 가격기준을 이야기하는 것이며 이는 ```LottoRule``` 클래스의 ```PURCHASE_UNIT``` 상수의 값을 수정함으로써 가격을 수정할 수 있습니다.

### 예외 처리
로또 가격 입력, 당첨 번호 입력, 보너스 번호 입력은 정수로만 한정됩니다. 따라서 다른 문자가 들어올경우 오류가 나오며 값을 재입력받습니다.   
당첨번호는 숫자 6개를 구분 문자로 구분하여 입력해야하며 숫자가 6개를 넘거나 부족한 경우 오류를 출력하며 값을 재입력받습니다.   
당첨 번호 입력의 숫자 구분은 ```,```로 구분됩니다.   
또한 당첨 번호는 숫자를 중복해서 쓸 수 없으며, 보너스 번호도 당첨 번호와 숫자가 겹치면 안됩니다. 이 경우에도 오류를 던지며 값을 재입력받습니다.   

### 실행 예시
실행 예시는 다음과 같습니다.
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 기능구현 목록

### 입력
- [x] 로또 구매 금액을 ```구입금액을 입력해 주세요.```라는 문구 이후에 입력받는다.   
- [x] 당첨 번호를 ```당첨 번호를 입력해 주세요.```라는 문구 이후에 입력받는다. 이때, 당첨번호는 컴마로 구분한다.   
- [x] 당첨 번호 문자열이 컴마로 시작하거나 끝나면 예외처리한다.
- [x] ```보너스 번호를 입력해 주세요.```라는 문구 이후 보너스 번호를 입력받는다.
- [x] 입력에 숫자가 아닌 문자가 들어갈 경우 예외처리한다.

### 출력
- [x] 발행한 로또 번호를 n개를 구매했으면 ```n개를 구매했습니다``` 라는 말과 동시에 출력한다.
- [x] 발행한 로또 번호를 출력한다.
- [x] 당첨 내역을 ```n개 일치 (n원) - n개``` 의 형식으로 출력한다.
- [x] 수익률을 소수점 두자리 수를 반올림하여 출력한다.

### 당첨 번호 저장
- [x] 당첨번호 문자열을 컴마를 기준으로 나눠서 저장한다.
- [x] 당첨번호가 6개 이상일 경우 예외처리한다.
- [x] 당첨번호가 1에서 45까지의 정수가 아닐경우 예외처리한다.

### 보너스 번호 저장
- [x] 보너스 번호를 저장한다.
- [x] 보너스 번호가 1에서 45까지의 정수가 아닐경우 예외처리한다.

### 로또 발매 기능
- [x] 1에서 45까지의 중복되지 않는 정수 6개를 랜덤하게 만든다.
- [x] 이를 오름차순으로 정렬한다.

### 로또 구매 기능
- [x] 구입금액에 맞는 로또를 사서 발행한다.

### 구매한 로또 저장
- [x] 구매한 로또의 번호 리스트를 저장한다.

### 로또 당첨 확인 기능
- [x] 구매한 로또의 번호 리스트와 당첨번호, 보너스 번호를 불러온다.
- [x] 이를 비교하여 기준에 맞게 등수와 금액을 저장한다.

### 수익률 계산 기능
- [x] 구매한 가격과 번 수익을 통해서 수익률을 계산한다.

### 예외 처리
- [x] 예외 상황 시 에러 문구를 출력한다.
- [x] 에러 문구는 ```[ERROR]```로 시작해야 한다.
- [x] 에러 메시지를 출력 후 예외 발생한 부분부터 입력을 다시 받는다.
