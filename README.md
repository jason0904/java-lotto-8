# java-lotto-precourse

## 프로젝트 개요
간단한 로또 구현기입니다.   
사용자는 실제 로또를 하는 것 같이 돈을 입력하여 로또를 구매하고, 당첨 번호를 입력받고, 보너스 번호를 입력하게 됩니다.   
그 후 구매한 로또 번호가 뜹니다.   
그 후 당첨번호와 로또 번호를 비교하고 당첨 내역을 출력합니다.   
그 후 그 수익률을 출력합니다.   

### 주요 기능
- 로또 구매 기능
- 로또 발행 기능
- 로또 당첨 확인 기능
- 로또 수익률 확인 기능

### 로또 당첨 기준
로또의 당첨기준과 내용은 다음과 같습니다.
- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원

### 입출력 예시
입력과 출력예시는 다음과 같습니다.
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 기능구현 목록

### 입력
- [ ] 로또 구매 금액을 ```구입금액을 입력해 주세요.```라는 문구 이후에 입력받는다.   
- [ ] 당첨 번호를 ```당첨 번호를 입력해 주세요.```라는 문구 이후에 입력받는다. 이때, 당첨번호는 컴마로 구분한다.   
- [ ] 당첨 번호 문자열이 컴마로 시작하거나 끝나면 예외처리한다.
- [ ] ```보너스 번호를 입력해 주세요.```라는 문구 이후 보너스 번호를 입력받는다.
- [ ] 입력에 숫자가 아닌 문자가 들어갈 경우 예외처리한다.

### 출력
- [ ] 발행한 로또 번호를 n개를 구매했으면 ```n개를 구매했습니다``` 라는 말과 동시에 출력한다.
- [ ] 발행한 로또 번호를 출력한다.
- [ ] 당첨 내역을 ```n개 일치 (n원) - n개``` 의 형식으로 출력한다.
- [ ] 수익률을 소수점 두자리 수를 반올림하여 출력한다.

### 당첨 번호 저장
- [ ] 당첨번호 문자열을 컴마를 기준으로 나눠서 저장한다.
- [ ] 당첨번호가 6개 이상일 경우 예외처리한다.
- [ ] 당첨번호가 1에서 45까지의 정수가 아닐경우 예외처리한다.

### 보너스 번호 저장
- [ ] 보너스 번호를 저장한다.
- [ ] 보너스 번호가 1에서 45까지의 정수가 아닐경우 예외처리한다.

### 로또 발매 기능
- [ ] 1에서 45까지의 중복되지 않는 정수 6개를 랜덤하게 만든다.
- [ ] 이를 오름차순으로 정렬한다.

### 로또 구매 기능
- [ ] 구입금액에 맞는 로또를 사서 발행한다.

### 구매한 로또 저장
- [ ] 구매한 로또의 번호 리스트를 저장한다.

### 로또 당첨 확인 기능
- [ ] 구매한 로또의 번호 리스트와 당첨번호, 보너스 번호를 불러온다.
- [ ] 이를 비교하여 기준에 맞게 등수와 금액을 저장한다.

### 수익률 계산 기능
- [ ] 구매한 가격과 번 수익을 통해서 수익률을 계산한다.

### 예외 처리
- [ ] 예외 상황 시 에러 문구를 출력한다.
- [ ] 에러 문구는 ```[ERROR]```로 시작해야 한다.
- [ ] 에러 메시지를 출력 후 예외 발생한 부분부터 입력을 다시 받는다.
